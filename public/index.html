Set up your first test

Five steps. Each one ticks itself from what pivitlab has actually seen. You can hide this list and carry on with the experiments underneath. It also disappears once every step has ticked.

This agency has more than one site. Choose which site the snippet and the first test are for. pivitlab remembers the choice.

  1. 1
    Add your site To do

    This is the website the test will run on. pivitlab only serves a test for the domains you add here. If you signed up with a website, this step is already ticked.

    Add the site you want to test.

  2. 2
    Install the snippet To do

    Paste this one line before the closing body tag on every page you might test. It includes your site key, so pivitlab can tell the visit is yours. In Google Tag Manager, add a Custom HTML tag with the same line and fire it on all pages. Then open the site in a browser. The status below updates on its own, usually within a few seconds. You can build a test before it ticks. You cannot start a test until it does.

              Preview with ?pivit_qa=1
              To do
              
    Open the page you are testing and add ?pivit_qa=1 to the address. pivitlab remembers that browser and treats the visit as a test, so those views stay out of the results. When you want this browser to count as a normal visitor again, open the same page with ?pivit_qa=0.

Looking before the planned sample raises the chance of a false win. A live probability can look decisive after a handful of conversions and still be noise.

      
This look will be marked as peeked, and that mark stays on the result. The planned verdict, when it arrives, will say the test was peeked.
